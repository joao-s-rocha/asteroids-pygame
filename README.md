# 🚀 Asteroids Clone

A simple clone of the classic arcade game Asteroids made with Python and Pygame.

## 🎮 Features

- Player movement with inertia
- Asteroid spawning
- Shooting system
- Screen wrapping
- Collision detection
- Score system

## 🛠 Technologies

- Python 3
- Pygame
